# ASSIGNMENT 04 [C04] – C Programming
## Structures, Unions, Pointers and Storage Classes

This repository contains six task folders with C source files, test cases, output evidence, design notes, pseudocode, and complexity analysis.

### Folder structure
- `Task01` – Patient register data-design review
- `Task02` – Nested structures and courier parcel tracking
- `Task03` – Tagged unions and memory layout
- `Task04` – Structure pointers and debugging
- `Task05` – Storage classes
- `Task06` – Canteen inventory and billing design challenge

### Compile
Use GCC:
```bash
gcc -Wall -Wextra -std=c11 filename.c -o program
```
Run:
```bash
./program
```
On Windows:
```powershell
program.exe
```

No student name or register number is included in this repository.
