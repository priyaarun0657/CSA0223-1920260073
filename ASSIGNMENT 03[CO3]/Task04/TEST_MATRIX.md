# Task04 Test Matrix

| Test | Input / scenario | Expected validation |
|---|---|---|
| T1 | Typical values | Correct normal result |
| T2 | Minimum-size input | No out-of-bounds access |
| T3 | Boundary values | Correct handling of first/last element |
| T4 | Missing/empty case | Correct failure or empty-case result |
| T5 | Duplicate/equal values | Stable or clearly defined behaviour |
| T6 | Large input | Algorithm behaves as expected for its complexity |

Specific tests: Test small hand-calculated matrices, negative values, all equal values, and boundary row/column indices.
