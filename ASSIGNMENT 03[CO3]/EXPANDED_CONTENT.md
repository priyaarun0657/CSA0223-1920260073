# Expanded Assignment Package

This expanded version includes the original task programs plus extra examples, task-specific notes, complexity explanations, test matrices and additional execution output screenshots.

## Added per task
- `additional_examples.c`
- `ADDITIONAL_OUTPUT.txt`
- `additional_output_screenshot.png`
- `EXPANDED_NOTES.md`
- `TEST_MATRIX.md`

The source assignment asks for individual/pair analysis, measured comparisons, graphs, a joint report and contribution records. The expanded package provides study notes and reproducible program examples; actual student-specific measurements, contribution records and report answers should be completed based on your own execution and pair-work.
