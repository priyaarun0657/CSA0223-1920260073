# ASSIGNMENT 05 [C05] – C Programming

Course: CSA02 – C Programming | Course Outcome: CO5

This repository contains 12 task folders with C source code, design notes, test data and execution-output screenshots. No student name or register number is included.

## Compile and run
Use GCC:
```bash
gcc -std=c11 -Wall -Wextra Task01/A1_Function_Decomposition.c -o task
./task
```
Each task has its own source file and `output.png` screenshot. Some benchmark measurements are documented as expected trends and must be measured on the student's own computer before final submission.
